# Signature V4.2
Isolated app branch/package. Native startup login and biometric settings, existing Android Keystore authentication and Firebase form, fixed app-only navy and gold styling and four navigation buttons. Existing live website engine is deliberately reused in a WebView to preserve calculations, data sync, PDFs and alerts. No WebView shown before successful account/cloud login; website appearance settings do not determine app theme. No new billing functions. This is a hybrid implementation, not a completed fully native rewrite. Device visual and end-to-end financial/Telegram tests still required; do not uninstall production app or use simultaneous writes until checked. Website and DB not changed by this commit.
